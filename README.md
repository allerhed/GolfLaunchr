# GolfLaunchr

iOS golf launch monitor (iPhone camera, side-on, landscape capture). English + Swedish. Spec: [docs/spec/INDEX.md](docs/spec/INDEX.md). Mockups: [docs/mockups/INDEX.md](docs/mockups/INDEX.md).

## Build
```bash
brew install xcodegen          # once
scripts/doctor.sh              # toolchain check
scripts/verify.sh --ui         # generate project, test packages + app, l10n parity
open GolfLaunchr.xcodeproj     # generated by verify.sh / xcodegen generate
```
Physical iPhone required for capture and measurement validation (spec gates G1/G2); the simulator covers UI and logic only.
